# Piece recognition model

`chess_piece_classifier.onnx` is the unmodified chessvision MobileNet V3 Small model by Harshit Pawar. The application embeds it at build time, so users do not need a separate model download.

- Model repository: https://huggingface.co/harshitpawar64/chessvision
- Source and preprocessing conventions: https://github.com/harshitpawar64/chessvision
- Upstream source license: [MIT notice](../../licenses/chessvision-MIT.txt)
- Size: 6,408,165 bytes
- SHA-256: `82171a74e8c8c51ba104eff5fc77fc10b1d9cc622bb11d4e7194730fbac9c7e9`

Input size, normalization, and class order are read from the model's metadata. Keep this file in Git alongside the source; no Git LFS configuration is required for this model.
