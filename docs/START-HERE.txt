FishEyes - offline chess overlay

1. Open FishEyes.exe.
2. Show a complete 2D chessboard on your screen.
3. Set target Search depth (1-40) and switch analysis On.
   Use - / +, or type a value and press Enter.

Stockfish 19 is included. First analysis unpacks the engine, source and license
under %LOCALAPPDATA%\FishEyes\engines. No internet or separate install needed.
Each side gets up to 500 ms of analysis, using up to two CPU threads and a
128 MB hash table (plus engine memory). The panel shows the actual depth reached.

Blue arrow: assumes White is to move. Orange arrow: assumes Black is to move.
Both arrows analyze the current position independently. Castling and en passant
are unavailable because a screenshot does not establish those rights.

Capture repeats as soon as each scan finishes. Two matching scans are needed.
Unchanged positions use a saved cache. A changed board cancels outdated analysis.
Switch Off to pause, cancel analysis and clear the arrows. Click Detected board
to inspect recognized pieces. Drag the header to move; use X or Alt+F4 to exit.
Tab moves between controls; Space activates a focused button.

For screenshots, close FishEyes then open FishEyes-Window.cmd beside the EXE.
This temporary window mode can be captured and shows arrows only in its preview.

Screen images and board positions stay on your PC. Python and a separate .NET
installation are not required. Keep the licenses folder when sharing the app.
Stockfish's license and source are also included inside the executable.

Limits: a full, visible, axis-aligned board is required. Orientation is inferred
from the pieces. Unfamiliar themes or unusual endgames may be misread.

Cache: %LOCALAPPDATA%\FishEyes\analysis-cache-local-v1.json
Windows x64. Native dependencies may need Microsoft's Visual C++ 2015-2022 x64
redistributable on a fresh PC.
