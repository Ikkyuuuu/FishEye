# Preview pieces

These 12 unmodified 150px Chess.com **Neo** sprites render the overlay's detected-board preview. They are embedded in the executable and require no runtime download.

Source URLs and SHA-256 hashes are recorded under the `Neo` entry (`711e8a54-b2f4-11ed-8d8e-8f97686604fd`) in [the theme manifest](../../themes/manifest.json). Filenames use `w`/`b` for color and `p`, `n`, `b`, `r`, `q`, `k` for piece type.
